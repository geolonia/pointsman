pointsman.net is the website of Pointsman, an open-source decision service:
the landing page and this documentation. Pointsman itself is a generic
open-source project under the MIT License. Anyone can run it.

## Operator

- Questions, proposals and bug reports:
  [GitHub issues](https://github.com/geolonia/pointsman/issues), in English
  or Japanese.
- Security problems: see the [security policy](../../SECURITY.md).
- Anything else: [Geolonia's contact form](https://www.geolonia.com/contact/)
  (in Japanese).

## Disclaimer

- Pointsman is not 1.0 yet. The API and the profile format may still change
  between 0.x releases; the [changelog](../../CHANGELOG.md) says how.
- Pointsman and this site are provided as they are, without any warranty.
- Between releases, this site shows the code on `main`, which may already
  have changes for the next version.

## Privacy

- This site sets no cookies and has no analytics and no forms.
- The documentation uses fonts served from this site. The landing page loads
  the font IBM Plex Mono (the Japanese page also IBM Plex Sans JP) from
  Google Fonts, so your browser connects to fonts.googleapis.com and
  fonts.gstatic.com when you open it.
- The search runs in your browser and sends nothing. Your choice of light or
  dark mode, and which parts of the sidebar are open, are kept in your
  browser only.
- Cloudflare, which hosts the site, processes ordinary access logs (IP
  address, browser type and similar) as far as needed to deliver it, and
  may receive your browser's reports of network errors.
- See also Geolonia's [privacy policy](https://www.geolonia.com/privacy/)
  (in Japanese).

If analytics or similar tools are ever added, this page will say so first.
