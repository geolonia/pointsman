# Data models

The `Decision` model (records of automated decisions: answers, rule, model,
facts, human involvement, chains) is published on datamodels.jp:

- Model: https://datamodels.jp/models/decision/Decision/
- Context: `https://datamodels.jp/context/decision/v1.jsonld`
- Schema: `https://datamodels.jp/schema/decision/Decision/v1.json`

It was drafted here (#16, #51, #52) and proposed in geolonia/datamodels#164.
The bridge's Decision entities follow it (`bridge/`); the tests use a pinned
copy (`test/fixtures/datamodels/decision/`).
