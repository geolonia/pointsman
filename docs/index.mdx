Pointsman is an open-source decision service. Your systems send it a
*case*, something to decide, for example a report of a closed road or a new
pull request. Pointsman asks an AI model fixed questions, looks up facts in
data, and applies rules that people wrote. The answer is an action. When it
is not sure, a person checks the case. Every decision is recorded.

New here? Read [How a decision is made](explanation/decision-model.md), then
try [Your first profile](tutorials/first-profile.md).
