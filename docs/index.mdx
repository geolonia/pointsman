---
title: Pointsman documentation
description: Pointsman decides which way a case goes, or calls a person when it is not sure. Learn to use it, look up the details, and read why it works as it does.
---

Pointsman is an open-source decision service. Your systems send it a case,
for example a report of a closed road or a new pull request. Pointsman asks
fixed questions, applies rules that people wrote, and answers with an action.
When it is not sure, a person checks the case.

The documentation has four parts:

- **Tutorials** teach by doing, step by step.
- **How-to guides** reach one goal, for example deploying Pointsman.
- **Reference** lists the facts: the profile format, the fact types, the HTTP API and the MCP tools.
- **Explanation** says why Pointsman works as it does.
