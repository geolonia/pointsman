Pointsman は、人やスクリプトだけでなく、AI エージェントからも使えるように作っています。エージェントは自分で判断する代わりにプロファイルに判定を頼み、その判定はすべて記録されます。

## このサイトの作り方

Pointsman のコードとこのドキュメントの多くは、AI の助けを借りて書いています。何を取り入れるかは人が決めます。どの変更もプルリクエストにして人がレビューしてマージし、CI が確かめます(テスト、生成するリファレンスのページ、全ページの 2 つの言語、すべてのリンク)。誤りを見つけたら、[Issue](https://github.com/geolonia/pointsman/issues) でお知らせください。

## このサイトを読む AI のツール向け

- **最初に読むもの:** [llms.txt](https://pointsman.net/llms.txt)。ドキュメントの全ページを 1 行ずつ説明した短い索引です(英語)。
- **すべてを 1 つのファイルで:** [llms-full.txt](https://pointsman.net/llms-full.txt)。英語の全ページの本文です。
- **API:** コードから生成した [HTTP API](../reference/http-api.md) と [MCP ツール](../reference/mcp-tools.md)。
- `robots.txt` では、検索、AI の回答、AI の学習のどれにも使ってよいとしています。

## AI アシスタントをつなぐ

Pointsman のデプロイは、どれも `/mcp` で MCP(Model Context Protocol。AI アシスタントがツールを呼び出すための仕組み)を提供します。

- **人**は GitHub でサインインします。入れるのは、そのデプロイが許可した GitHub の組織のメンバーだけです。Geolonia 自身のデプロイは `https://mcp.pointsman.net/mcp` にあり、Geolonia のチームが使っています。ご自身で Pointsman を使うときは、[デプロイ](../../deployment.md)(英語)して、そのアドレスを使ってください。
- **スクリプトや CI** は、API トークン(`Authorization: Bearer <token>`)で MCP か HTTP API を使います。トークンはクライアントごとにあり、使えるプロファイルを限定できます。[API トークンを入れ替える](../how-to/rotate-api-tokens.md)も参照してください。

Claude Code では、次のコマンドでサーバーを追加します。

```sh
claude mcp add --transport http pointsman https://mcp.pointsman.net/mcp
```

Claude Desktop と claude.ai では、コネクターの設定で、同じ URL のカスタムコネクターとして追加します。API トークンを使う場合も含めた詳細は、[MCP サーバー](../../mcp.md)(英語)のページにあります。

## エージェントにできること、できないこと

エージェントにできること:

- 使えるプロファイルを一覧し、ふつうの文章で読む。
- プロファイルに判定を頼み、あとからその判定を読み直す。
- 変更したポリシーを、これまでの判定で試す(リプレイ)。何も変更しません。
- GitHub でサインインした人として使うときは、判定の回答を訂正する。

エージェントにできないこと:

- プロファイルやルールを変える。プロファイルは、人が自分たちの設定用リポジトリから公開します。
- クライアントの範囲外のプロファイルを使う。範囲外のプロファイルは、存在しないものとして扱われます。
- 記録されない判定をする。判定はすべて、頼んだクライアントの名前で記録されます(人の場合は `github:<login>`)。
- MCP でレビューを決める。アクションが `review` の判定は人の確認を待ち、MCP にはそれを決めるツールがありません。HTTP API では、そのプロファイルを使えるトークンを持つクライアントならレビューを決められます([Reviews and callbacks](../../reviews.md)、英語)。そのようなトークンは、レビューする人が使うツールにだけ渡し、エージェントには渡さないでください。

外部の人が書いた入力を扱うプロファイルでは、AI の回答は判定を厳しくする方向にしか使いません。[その理由](../explanation/stricter-only.md)も参照してください。

## アシスタントとプロファイルを書く

アシスタントがプロファイルの下書きを書き、Pointsman 自身のツールで確かめます。スキーマ、文章にしたルール、テストケース、これまでの判定でのリプレイです。内容を承認するのは人です。詳しくは [AI アシスタントとプロファイルを書く](../../authoring.md)(英語)を参照してください。
