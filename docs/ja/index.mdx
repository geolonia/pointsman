Pointsman は、オープンソースの判定サービスです。ほかのシステムから、判定してほしいもの(ケース)を受け取ります。たとえば、道路が通れないという報告や、新しいプルリクエストです。Pointsman は決まった質問をし、人が書いたルールを当てはめ、アクションを返します。確信がないときは、人がケースを確認します。

はじめての方は、まず[判定のモデル](explanation/decision-model.md)を、次に[プロファイルの概要](reference/profiles.md)を読んでください。
