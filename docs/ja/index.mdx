Pointsman は、オープンソースの判定サービスです。ほかのシステムから、判定してほしいもの(ケース)を受け取ります。たとえば、道路が通れないという報告や、新しいプルリクエストです。Pointsman は AI モデルに決まった質問をし、データからファクトを調べ、人が書いたルールを当てはめて、アクションを返します。確信がないときは、人がケースを確認します。判定はすべて記録されます。

はじめての方は、まず[判定のしくみ](explanation/decision-model.md)を読み、次に[はじめてのプロファイル](tutorials/first-profile.md)を試してください。自分のコンピューターで動き、クラウドのアカウントは要りません。自分でのデプロイや FIWARE など、ほかの使い方に必要なものは[使い方を選ぶ](how-to/choose-a-setup.md)にあります。

## チュートリアル

- [はじめてのプロファイル](tutorials/first-profile.md): 自分のコンピューターで Pointsman を動かし、プロファイルを書いて判定させます。
- [本物の AI で判定する(写真付き)](tutorials/real-answers.md): 本物の AI モデルが文章と写真から答え、ルールを直します。
- [オンラインで動かす](tutorials/put-it-online.md): 非公開の GitHub リポジトリから、自分の Pointsman を Cloudflare にデプロイします。
