# 日本語の用語と表記

Pointsman の日本語のドキュメント(`docs/ja/`)、ランディングページ(`site/ja/`)、生成するリファレンスの日本語の文(`scripts/docs-reference.mjs`)で使う言葉です。1 つの概念には 1 つの言葉を使います。新しい言葉が必要になったら、使う前にこの表に加えてください。

英語のページは英語で、日本語のページは日本語で書きます。文ごとに翻訳しません([CONTRIBUTING.md](../CONTRIBUTING.md))。

## 表記

- 全角と半角の間に半角スペースを入れます(`API トークン`、`15 分`)。句読点と括弧の隣には入れません。
- 丸括弧は半角 `()` を使います。
- 数字は半角です。パーセントは数字に続けます(`70%`)。コマンドの出力は、出力のとおりに書きます(`70 %`)。
- 長音を付けます: コンピューター、サーバー、ブラウザー、フォルダー、ユーザー、パラメーター、エディター、レビュアー、エントリーポイント。
- 本文はです・ます調で書きます。体言止めは見出し、表、リストの短い項目だけにします。
- 横棒(──)は使いません。
- 英語のままのページへのリンクには「(英語)」を付けます。
